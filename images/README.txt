Place your real product/lifestyle photos in this folder.
Each spot where a photo belongs is marked in the HTML with a placeholder
box and a comment showing the exact <img> tag to use, e.g.:

  <!-- Replace above with: <img src="images/your-photo.jpg" alt="Hero Banner Image"> -->

Just swap the placeholder <div class="img-placeholder">...</div> for that
<img> tag, pointing at a real file you've placed in this folder.
